# Psi — instaladores

Psi é um programa para psicólogas e psicólogos autônomos organizarem pacientes, agenda, prontuário e financeiro. Os dados ficam **somente no seu computador**, protegidos por senha.

## [⬇ Baixar a última versão](https://github.com/angelicadf97/psi-releases/releases/latest)

Na página que abrir, baixe o arquivo **`Psi_..._x64-setup.exe`** (o instalador para Windows 10 ou 11).

## Como instalar

1. Execute o instalador baixado. Ele instala só para o seu usuário e **não pede senha de administrador**.
2. Se o Windows avisar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador ainda não tem certificado comercial).
3. Abra o Psi, crie sua senha no primeiro acesso e **guarde a chave de recuperação** que o app mostrar.

## Atualizações

O Psi avisa quando há uma versão nova ao abrir. Seus dados ficam em `%APPDATA%` e são mantidos ao atualizar, reinstalar ou desinstalar.
